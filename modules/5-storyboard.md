# مرحله‌ی ۶: استوری‌بورد

**هدف:** ریل فریم‌به‌فریم، طوری که تیم تولید بدون سؤال اضافه بسازدش. با تأیید کارفرما ایده وارد مرحله‌ی تولید می‌شود.

## ساختار ریل
- ۴ تا ۸ فریم، ۹:۱۶، معمولاً ۱۵ تا ۴۵ ثانیه.
- فریم ۱ = هوک (۰ تا ۳ ثانیه). شروع مستقیم، بدون مقدمه.
- وسط: قدم‌ها یا بدنه‌ی اصلی، هر فریم یک ایده.
- آخر: پاداش یا نتیجه، بعد CTA (سؤال برای کامنت، ذخیره، یا معرفی محصول) و لوگو.
- همان چیزی را نگه دار که ریل منبع را موفق کرده (و QC گفته). رنگ‌ها و حس از `visual` پیج.

## فیلدها
`WORK/ideas/<id>-storyboard.json`:
```json
{
  "style": "نور طبیعی، رنگ گرم ملایم، زیرنویس دست‌نویس",
  "music": "lo-fi آروم، ۸۵ BPM",
  "caption": "کپشن پیشنهادی کوتاه",
  "palette": ["#3B2A20", "#C8A27A", "#F3E9DC", "#6B8F71"],
  "frames": [
    {"shot": "closeup", "time": "۰–۲s", "dur": 2,
     "visual": "قطره‌ی قهوه از فیلتر می‌چکه",
     "text": "قهوه‌ت تلخه؟",
     "vo": "اگه قهوه‌ی خونگیت تلخه…",
     "camera": "ماکرو، اسلاید آروم", "sfx": "چکه", "transition": "کات روی ضرب",
     "sketch": "f1.svg"}
  ]
}
```
- `shot` یکی از این‌هاست و داشبورد برایش طرح خطی می‌کشد:
  `closeup` کلوزآپ، `wide` نمای باز، `pov`، `topdown` نمای بالا، `text` تیتر تمام‌صفحه، `split` تقسیم صفحه، `product` محصول، `person` آدم، `hands` دست‌ها، `infographic`، `map` نقشه، `screen` صفحه‌ی گوشی، `timelapse`، `logo`، `transition`
- `text` = متن روی صفحه (کوتاه)، `vo` = نریشن یا دیالوگ. هرکدام نیست، نگذار.
- `palette` اختیاری است؛ اگر نباشد، پالت پیج استفاده می‌شود.
- `sketch` اختیاری: طرح اختصاصی فریم. یک فایل SVG ساده با `viewBox="0 0 1080 1920"` (فقط شکل و متن، بدون اسکریپت) یا PNG، در پوشه‌ی `WORK/ideas/<id> - <عنوان>/`. اگر ابزار ساخت تصویر وصل است، فقط با درخواست کاربر و بعد از گفتن هزینه از آن استفاده کن.

## ثبت
`RUN storyboard <id> --file "<فایل>"`
- `storyboard.md` در پوشه‌ی ایده ساخته می‌شود و روی داشبورد هر فریم با واترمارک «© tarfandhaye.ai» دیده می‌شود.
- به کاربر بگو کارفرما روی داشبورد (کارت ایده ← تب استوری‌بورد) **تأیید** یا **نیاز به اصلاح** بزند.

## اصلاح
- `RUN status` یادداشت کارفرما را نشان می‌دهد («استوری‌بورد را اصلاح کن — یادداشت: …»).
- فقط همان را درست کن و دوباره `RUN storyboard <id> --file …` بزن. نسخه یکی بالا می‌رود و دوباره منتظر تأیید می‌شود.

## بعد از تأیید
ایده «در تولید» است. اگر پروژه‌ی ساخت ریل (موشن یا تدوین) جداگانه دارید، از `preprod.md` و `storyboard.md` همین پوشه شروع کن. وقتی ریل ساخته شد: `RUN done <id>`.
